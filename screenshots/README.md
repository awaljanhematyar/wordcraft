# Actual browser screenshots

phase6-desktop.jpg and phase6-mobile.jpg were captured on 2026-10-23 from the actual running WordCraft app in Linux Chromium, UA Chrome/155.0.0.0 (reduced version). The game shows a genuinely restored completed Daily puzzle with accepted HELLO and ARENA rows. No mockup or generated game UI was used.

The same-origin tests/handoff-preview.html fixture uses a 1440×1200 CSS-pixel app viewport for desktop and 390×1200 for mobile. The outer capture wrapper displays the iframe at 70% scale without changing app styles or its CSS viewport. Desktop output is 1008×840 pixels. Mobile raw viewport output is 1363×936 pixels and includes surrounding fixture background. Screenshot clipping/full-page calls timed out in this environment, so supported viewport captures were retained. Files are unedited browser bytes. They demonstrate responsive rendering, not physical-device testing.

Historical phase4 and phase5 captures remain as prior evidence. They are not new Phase 6 measurements. Do not present these files as proof of Firefox, WebKit, physical touch, screen-reader speech or 200% browser-zoom execution.
