# Assets

favicon.svg is original WordCraft vector artwork from Phase 1.

WORDNIK_LICENSE.txt is the complete unmodified MIT license for the bundled Wordnik-derived dictionary. Preserve it with redistributed word data. WORD_LIST_PROVENANCE.md describes the pinned primary source, transformation, curation, and usage terms. WORD_LIST_MANIFEST.json records the revision, counts, and SHA-256 digests. Actual data lives in js/words.js, so browser runtime requests no external dictionary or API.

Actual game screenshots are in screenshots/. A dedicated social card, canonical URL, og:url and an absolute og:image URL must be finalized once the publication origin is approved. No placeholder deployment URL is shipped.
